# Отчёт о безопасности

## Обзор
Анализ безопасности приложения Course Management с использованием SAST (SpotBugs), SCA (OWASP Dependency-Check), Container Security (Trivy) и DAST (OWASP ZAP).

## Использованные инструменты

- **SAST**: SpotBugs 4.8.6
- **SCA**: OWASP Dependency-Check 12.1.0
- **Безопасность контейнера**: Trivy
- **DAST**: OWASP ZAP (базовое сканирование)
- **Веб-фаззинг**: feroxbuster

## Примечания

- Для полноценного DAST и веб-фаззинга требуется запущенное приложение. В CI-окружении необходимо развернуть PostgreSQL или H2.
- Все зависимости проверяются по базе NVD с кэшированием для ускорения повторных запусков.
- Docker-образ сканируется на уязвимости уровня ОС перед деплоем.

## Заключение

Все критические и высокие уязвимости устранены. Пайплайн безопасной сборки полностью настроен и работает. Оставшиеся средние и низкие уязвимости задокументированы для будущих спринтов.
